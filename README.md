# LUNUX
Kind of a parody of "linux"... Think of lunux as a linux-like operating system. 

## Current Functionality
Nothing! All it can do right now is print things to the screen, but more will come! 

## PACKAGES NEEDED
- nasm, build-essential, bison, flex, libgmp3-dev, libmpc-dev,  libmpfr-dev, texinfo, libisl-dev, qemu-system, gcc

## BUILDING
All you have to do is run /src/buildall.sh, and then /src/run.sh I might make a get packages script, but I dont know how well that will transfer across operating systems, so thats a feature that might come later.
